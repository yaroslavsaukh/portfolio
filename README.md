# Yaroslav Saukh — Portfolio

Готовий статичний сайт-портфоліо українською, без залежностей і без build-кроку.

## Запуск

```bash
cd yaroslav-portfolio
python3 -m http.server 5173
```

Відкрийте `http://localhost:5173`.

## Deploy на Vercel

1. Завантажте цю папку в GitHub як окремий репозиторій.
2. У Vercel виберіть **Add New → Project → Import repository**.
3. Framework Preset: **Other**. Build Command: **порожньо**. Output Directory: **`.`** (корінь).
4. Deploy. Файл `vercel.json` вже включено.

Альтернатива: `npx vercel --prod` із кореня проєкту за наявності Vercel CLI та доступу до акаунта.

## Структура

- `index.html` — головна сторінка.
- `styles.css` — повний дизайн і responsive breakpoints.
- `script.js` — мобільне меню, фільтри, актуальний рік.
- `demos/` — чотири незалежні HTML-демо.
- `assets/Yaroslav-Saukh-CV.pdf` — прикріплене резюме.

## Контент / важливі перевірки

- **Проєкти:** ÉPURE, VERDICT, ROUGH CUT, FORMA — демонстраційні концепти, не клієнтські замовлення. Ніколи не представляйте їх як реалізовані для реальних замовників без відповідного підтвердження.
- **Бюджети й строки:** ілюстративні оцінки, не фактичні гонорари чи строки реалізованих контрактів.
- **Контакти:** email і Telegram узято з резюме. Перевірте перед публікацією.
- **Досвід:** базується на резюме, дані можуть потребувати актуалізації.
- **Демонстрації:** зовнішні фотографії або шрифти деяких demo можуть потребувати доступу до мережі.
- Не має бекенду форми — контакти відкривають Telegram/email; це робочий сценарій без збору персональних даних на сервері.
